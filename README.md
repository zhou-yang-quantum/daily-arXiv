# daily-arXiv

A personal daily selection of arXiv papers, tailored to my research interests.

## Status

Repository initialized. Paper collection, personalized filtering, and the website are planned next.

## Planned features

- Fetch new arXiv submissions daily.
- Filter and rank papers using configurable research interests.
- Publish daily selections and a browsable archive on GitHub Pages.
- Run scheduled updates with GitHub Actions.
